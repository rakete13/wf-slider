WF Slider · v1.0.0 · Begleiter zu WF Anim

Slider per Attribut, für CMS und statische Inhalte.

Wrapper bauen, data-slider="carousel" setzen, fertig. Ob die Slides aus einer Collection List kommen oder von Hand gebaut sind, ist egal. Pfeile, Punkte und Zähler gestaltest du selbst im Designer und markierst sie nur.

Braucht nur GSAP selbst, keine Plugins. Läuft auf der veröffentlichten Seite, nicht im Designer. Mit ?wfslider-debug an der Adresse siehst du Hinweise zu jedem Slider in der Konsole.
00

Einbau

  1. GSAP aktivieren: Settings → GSAP integration → GSAP einschalten. Weitere Plugins sind nicht nötig.
  2. Head Code: webflow/head-code.html in Site Settings → Custom Code → Head Code (oder nur auf der Seite mit Slider).
  3. Footer Code: webflow/footer-code.html am besten als Page Custom Code auf den Seiten mit Slider. So bleibt das Site-Limit frei für WF Anim.
  4. Veröffentlichen.

Aufbau im Designer

slider-wrapper          ← data-slider = carousel
  ├── Collection List Wrapper
  │     └── Collection List   ← wird automatisch als Track erkannt (Display: flex, Gap)
  │           └── Collection Item  ← eine Slide (Flex Shrink 0, Breite)
  └── slider-controls
        ├── button-prev      ← data-slider-prev
        ├── dots             ← data-slider-dots (ein gestalteter Punkt als Vorlage darin)
        ├── button-next      ← data-slider-next
        └── counter          ← data-slider-current / data-slider-total

Ohne CMS markierst du den Track mit data-slider-track. Die Kinder des Tracks sind die Slides. Sollen nur bestimmte Kinder Slides sein, markierst du sie mit data-slider-slide.

02

Fade

Überblenden für Hero-Bereiche und Testimonials. Wischen funktioniert trotzdem. Inhalte in der Slide animieren mit data-slider-anim bei jedem Wechsel neu.

Neu

Slider, die sich an euer CMS halten.

Collection List rein, Attribut dran, fertig.

Barrierefrei

Tastatur, Screenreader, Bewegung reduzieren.

Alles eingebaut, ohne dass ihr daran denken müsst.

Leicht

Nur GSAP, keine Plugins.

Kein Swiper, kein externer Server.

Flexibel

Pfeile, Punkte, Zähler: alles im Designer.

Die Library markiert nur, gestaltet wird bei euch.

slider-wrapper   data-slider="fade"  data-slider-id="hero"  data-slider-autoplay="5"
headline         data-slider-anim="fade-up"     (fade-in, fade-up, fade-down, fade-left, fade-right, scale-in, blur-in, clip-up)

Bedienelemente außerhalb des Wrappers bekommen die ID als Wert:
button-prev      data-slider-prev="hero"
dots             data-slider-dots="hero"

Referenz

Einstellungen am Wrapper

AttributWirkung
data-slidercarousel, fade oder thumbs
data-slider-idName für Bedienelemente außerhalb, Thumbnails und die API
data-slider-loopEndlos (carousel). Fade ist standardmäßig endlos, ="false" schaltet ab
data-slider-alignstart (Standard), center, end
data-slider-autoplayAutomatisch weiter, Wert in Sekunden (ohne Wert 5)
data-slider-stepSlides pro Klick, Zahl oder page (alle sichtbaren)
data-slider-startStart-Slide, ab 1
data-slider-rewindOhne Loop: am Ende wieder zum Anfang
data-slider-duration / -easeDauer und Easing der Bewegung
data-slider-snap="false"Freies Ziehen ohne Einrasten
data-slider-drag="false"Kein Ziehen/Wischen
data-slider-wheel="false"Kein waagerechtes Trackpad-Wischen
data-slider-keyboard="false"Keine Pfeiltasten
data-slider-pause-hover="false"Autoplay läuft beim Hover weiter
data-slider-overflow="visible"Slides über den Rand hinaus zeigen (Clip dann an einem Eltern-Element)
data-slider-mediaNur aktiv bei dieser Media Query, z. B. (max-width: 991px)
data-slider-mobile="false"Unter 768 px kein Slider
data-slider-padZähler mit führenden Nullen, z. B. 2 → 03
data-slider-labelName für Screenreader
data-slider-forNur bei thumbs: ID des gesteuerten Sliders

Markierte Elemente

AttributElement
data-slider-trackReihe der Slides (bei Collection Lists automatisch)
data-slider-slideOptional: nur diese Kinder sind Slides
data-slider-viewportOptional: Element, das abschneidet (sonst Eltern-Element des Tracks)
data-slider-prev / -nextPfeile. Div, Link Block oder Button
data-slider-dotsContainer für Punkte. Das erste Kind ist die Vorlage
data-slider-current / -totalZähler
data-slider-progressFortschritt (Autoplay-Zeit, sonst Position)
data-slider-pausePause/Play für Autoplay
data-slider-animInhalt in einer Slide animieren. Dazu -delay, -duration, -distance, -stagger, -ease
data-slider-nodragIn diesem Element startet kein Ziehen (z. B. Video-Steuerung)

Klassen zum Gestalten

is-activeAktive Slide, aktiver Punkt, aktives Thumbnail
is-in-viewSlides, die gerade sichtbar sind
is-disabledPfeil am Anfang/Ende ohne Loop
is-draggingWrapper, während gezogen wird
is-pausedWrapper, wenn Autoplay per Button pausiert ist
is-staticWrapper, wenn alle Slides hineinpassen (Bedienelemente werden ausgeblendet)
is-emptyWrapper bei leerer Collection

API

const s = WFSlider.get('hero');          // per ID oder Element
s.next(); s.prev(); s.goTo(2);           // Index ab 0
s.play(); s.pause(); s.index; s.length;
s.on('change', ({ index, slide }) => {});
document.querySelector('[data-slider-id="hero"]')
  .addEventListener('wfslider:change', (e) => console.log(e.detail.index));

WFSlider.init(scope);   // neue Slider starten (z. B. nachgeladene Inhalte)
WFSlider.refresh();     // neu messen
WFSlider.destroy(scope);
